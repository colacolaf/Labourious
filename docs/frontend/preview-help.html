12 optional tweaks
  1. Move the persistent strip to the top instead of bottom (some apps prefer it above the input).
  2. Add an in-modal search input at the top — filter keys by typing `/nvda`.
  3. Drop the strip entirely — modal-only mode (H1) for users who hate the row.
  4. Show the strip's keys in `solid` style and labels in soft gray (current), or invert (keys gray, labels bold).
  5. Replace the right-corner "?" pill with a fixed corner <kbd>?</kbd> badge in absolute bottom-right.
  6. Group `Help` first (since it's the key the user just pressed), or last (less special).
  7. Add a tiny "source of truth" footer note: "Bindings live in docs/frontend/keys.py — this modal renders them."
  8. Stack the columns differently for narrow terminals (<90 cols): collapse to one column.
  9. For very wide terminals (>120 cols), spread across 3 columns instead of 2.
  10. Use ASCII `Enter` instead of `⏎`, plain `^` instead of `⌘`, for terminals that don't render glyphs.
  11. Show the current screen's keys faintly in bold (highlight in-modal) so the user knows where they are.
  12. Add a `/` jump-to-section key while modal is open (e.g. press `g` to jump to Global).
